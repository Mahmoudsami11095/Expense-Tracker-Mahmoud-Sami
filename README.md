# Mini Budget App

A simple Expense Tracker application that helps users record, manage, and analyze their daily expenses. Built with vanilla JavaScript and Tailwind CSS.

## Features

- **Add Expense**: Record new expenses with title, amount, category, and date.
- **Delete Expense**: Remove expenses from the list.
- **Filter by Category**: View expenses for specific categories (Food, Transport, Utilities, etc.).
- **Total Calculation**: Real-time calculation of total expenses.
- **Highest Expense**: Automatically highlights the single highest expense.
- **Local Storage**: Data persists across browser sessions.
- **Responsive Design**: Works on desktop and mobile devices.

## Technologies Used

- **HTML5**: Semantic structure.
- **Tailwind CSS**: Utility-first styling for a modern, responsive UI.
- **JavaScript (ES6+)**: Core logic using modern features like:
    - Arrow functions
    - Array methods (`map`, `filter`, `find`, `reduce`, `sort`)
    - Destructuring and Spread operator
    - LocalStorage API

## Setup and Usage

1. **Clone the repository**:
   ```bash
   git clone <repository-url>
   ```
2. **Open the project**:
   Navigate to the project folder.
3. **Run the app**:
   Open `index.html` in your web browser.

## Development

To modify styles, ensure you have Tailwind CSS installed or use the provided output file.
```bash
npm install
npm run build
```
